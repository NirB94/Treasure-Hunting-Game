# Treasure-Hunting-Game
A prototype of the Pumpkin game, initially was a treasure hunting game - find 3 keys and get the treasure chest.

To download and play game:
1. Go to Releases (To the right, below About section).
2. Download Pumpkin.Game.Pre-Alpha.zip file.
3. Unzip.
4. Run TreasureHuntingGame.exe file.
5. Enjoy!
